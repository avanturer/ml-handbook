# GAPS — сводная дельта прочёса

> Сведено из семи прочёсов в `.handbook/sweep/`: `ru-universities`, `ru-industry`, `intl-courses`,
> `github-awesome`, `company-handbooks`, `books-modern`, `frontier-2025`.
> Дата: 2026-07-27. Редактор: главный редактор хендбука.

## Как это собрано

- Исходно: **331 строка дельты** в семи файлах, **~200 источников** просмотрено,
  **~150 программ** выписаны целиком.
- Дедупликация: одна и та же тема встречалась под разными именами в 2–6 прочёсах
  (генеративные модели, fairness, основы RL, разметка, roofline/GPU, KV-кэш, HPO).
- **Дополнительная проверка, которой не делали шесть из семи агентов:** каждая тема
  прогнана `grep`-ом по **написанным главам** `docs/**` (133 файла), а не только по манифесту
  `STRUCTURE.md`. Часть «пробелов» оказалась уже закрытой в тексте глав (MinHash/LSH, MMR/DPP,
  CUPAC, Model Cards, reservoir sampling, каппа Коэна, CheckList, расстояние Кука, VIF, QAT,
  Huber, HyperLogLog, RNN-T/VAD/keyword spotting, importance weighting, loss spikes) — такие
  строки перенесены в **Отсев** с пометкой «уже покрыто».
- Итог: **93 уникальных пробела**, из них **P0 — 21**, **P1 — 38**, **P2 — 34**.

Колонка «Ист.» — в скольких из 7 независимых прочёсов тема всплыла.

### 2.2. Вне профиля MLE-собеса (нишевое или чужой домен)

- **Neural ODE, FFJORD, SDE и уравнение Фоккера–Планка, дискретная диффузия для последовательностей**
  (DGM L9–L14) — уровень исследователя генеративных моделей, не MLE. Достаточно того, что войдёт
  в новую главу по генеративным моделям на уровне DDPM/DDIM/flow matching.
- **NeRF, синтез новых видов, оптический поток, monodepth, разреженные 3D-свёртки, SLAM, робототехника,
  автономные автомобили** — отдельные домены. `13-optional/01` заявлен как «минимум для не-CV инженера»,
  расширять до 3D-графики бессмысленно.
- **POMDP, inverse RL, imitation learning вглубь, offline RL** — за исключением одного абзаца про
  behavior cloning в связке с обучением на логах (это войдёт в новую главу по основам RL).
- **Классическое CV вне нейросетей** (RANSAC, integral images, image registration) — актуально только
  для CV-вакансий с геометрией.
- **Edge / TinyML / MCUNet / on-device training / патч-инференс** — три прочёса подняли, но это
  мобильные и IoT-команды. Оставить один абзац в `07-mlops/09`, главу не заводить.
- **Sustainable AI, углеродный след, охлаждение кластера** — на MLE-собесах не спрашивают; один абзац

- **Model editing (точечная правка знаний в весах)** — исследовательская тема, в проде почти нет.
- **CUDA вглубь (CUTLASS, SASS, tensor-core intrinsics)** — уровень senior perf-инженера. Нам нужен

- **Теория нечётких множеств** (PZAD) — мёртвая ветка.
- **Гауссовы процессы и байесовские нейросети вглубь** — оставить одну строку как базу под байесовскую
  оптимизацию в главе про HPO; отдельного раздела не заводить.
- **Синтаксический разбор, семантические роли** (SLP3 гл. 18–21) — для middle+ MLE не окупается.
- **Privacy-preserving inference (FHE / MPC)** — один абзац с честным «дорого» внутри темы безопасности,

### 2.3. Устарело или заведомо не в проде — только с честной пометкой «в статьях»

- **Диффузия как основной рекомендер**, **агентный RL в продовых рекомендательных системах**,
  **латентное сжатие цепочек рассуждений**, **non-transformer архитектуры в массовом проде** —

### 2.5. Спорные — оставляю решение за автором раздела

- **DDIA-слой (репликация, шардирование, CAP, консенсус, уровни изоляции)**. За: всплывает,

  знать про консистентность онлайн/офлайн-хранилища» на 500–700 слов, без CAP-теоремы вглубь.
- **EDA и визуализация как отдельная тема** (три лекции у Дьяконова, модуль у МТС). За: треть первого

  превращается в галерею графиков. Компромисс: раздел «что смотреть перед моделированием» в

  сказать «на этих данных обучаться нельзя». Против: юрисдикционно и быстро устаревает.
  Компромисс: абзац в `05-llm/02` без перечисления конкретных лицензий.
