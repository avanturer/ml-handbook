   methods and data)

   Prompt Engineering, Jailbreaking and Prompt Injection, Information Extraction, Defenses)

   **RAG Beyond Texts**; Agents (Overview, Tools, Planning, **Agent Failure Modes and Evaluation**);
   **Memory**

   **Memory Math**, Numerical Representations, Quantization); Finetuning Techniques (PEFT,
   **Model Merging and Multi-Task Finetuning**, Finetuning Tactics)
